Install Mind Math Motion

Add Mind Math Motion to your home screen for quick access to tutoring, scheduling, and educational resources. It's free to install, and no App Store download is required.

iPhone & iPad

  1. Open this website in Safari.
  2. Tap the Share button (square with an upward arrow).
  3. Select Add to Home Screen.
  4. Enable Open as Web App if available.
  5. Tap Add.

The Mind Math Motion icon will appear on your Home Screen.

Android

  1. Open this website in Google Chrome.
  2. Tap the three-dot menu in the top-right corner.
  3. Select Install app or Add to Home screen.
  4. Follow the prompts to confirm.

Your app will be accessible from your Home Screen.

Windows & Desktop

  1. Open this website in Chrome or Microsoft Edge.
  2. Look for the install icon in the address bar, or open the browser menu.
  3. Select Install if available.
  4. Confirm the installation.
